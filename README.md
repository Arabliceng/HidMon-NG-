HidMon_ng (HID Keyboard Monitoring & Management Utility) is a Windows-based security and monitoring application designed to detect, manage, and monitor Human Interface Device (HID) keyboard devices. It provides users with control over newly connected keyboards, monitors keyboard-related activity, and identifies potentially suspicious keyboard-injected commands.

Application Feature

A) Real-Time HID Keyboard Detection

Continuously monitors the system for connected HID keyboard devices. It detects newly connected keyboards and identifies device connection events in real time, allowing administrators to maintain visibility over keyboard devices connected to the computer.

 Application Modes:
1. Block Mode
Prevents newly connected HID keyboard devices from being used without authorization. This mode is designed to protect systems against unauthorized keyboard connections, including potentially malicious HID devices. Administrative privileges are required to enable this functionality.

2. Allow Mode
Allows newly connected HID keyboard devices to operate normally. This mode is intended for trusted environments where users need to connect additional keyboards without restrictions.

3. Investigate Mode
Monitors keyboard-injected commands to help identify potentially suspicious input activity. It operates without interfering with normal system functionality, allowing users to investigate keyboard-related behavior while maintaining regular system operation.

4. Monitor Mode
Automatically monitors newly connected HID keyboards and observes keyboard-injected commands without interrupting normal system operation. This mode provides continuous visibility into keyboard activity and helps administrators identify potentially suspicious behavior. Administrative privileges may be required.



B). Blocked Device Reports
Generates reports containing information about HID keyboard devices that have been blocked. These reports help administrators review unauthorized connection attempts and maintain records of device management activities.

C). Keyboard-Injected Command Detection Reports
Generates lists of detected keyboard-injected commands. This functionality helps administrators investigate suspicious keyboard activity and identify input patterns that may require further security analysis.
